HCR2 Ultimate Control — Web App

This is a standalone companion/demo. It does not modify Hill Climb Racing 2, provide in-game currency, unlock official vehicles, or connect to game servers.

PUBLISHING:
1. Create a GitHub account at https://github.com if you don't already have one.
2. Create a new PUBLIC repository named hcr2-ultimate-control.
3. Upload all files in this folder to the repository root (index.html, manifest.webmanifest, sw.js, icons).
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. Open the HTTPS URL it gives you on your iPhone in Safari.
6. In Safari tap Share > Add to Home Screen > Add.

Note: iOS Add to Home Screen is an Apple built-in feature; no App Store app is needed.
